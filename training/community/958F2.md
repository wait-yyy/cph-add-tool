# 958F2 题解（AI）

## 题意

给定长度为 \(n\) 的颜色序列 \(a\)，以及每种颜色需要的人数 \(k_1,\dots,k_m\)。  
可以删除任意一些人，使得在剩余序列中存在一段连续的区间，其中颜色 \(i\) 恰好出现 \(k_i\) 次。  
要求最小化删除人数；若不可能，输出 \(-1\)。

---

## 关键观察

我们不需要关心目标区间外面的武士，因为他们是否留下不会影响“存在一段满足要求的区间”这件事。  
因此可以只考虑：在原序列中选出一个区间，删掉其中多余的武士，使得每种颜色恰好剩下 \(k_i\) 个。

若原序列中某个区间 \([l,r]\) 满足：

\[
\text{cnt}_i(l,r) \ge k_i \quad \text{对所有颜色 } i
\]

那么我们可以从这个区间中每种颜色只保留 \(k_i\) 个，删掉其余元素。  
需要删除的人数为：

\[
(r-l+1)-\sum_i k_i
\]

记

\[
K=\sum_i k_i
\]

于是问题转化为：

> 找到一个最短的区间，使得其中每种颜色 \(i\) 的出现次数都至少为 \(k_i\)。  
> 若最短长度为 \(L_{\min}\)，答案为 \(L_{\min}-K\)。

---

## 算法

使用双指针滑动窗口。

维护当前窗口 \([l,r]\)，以及：

- `cnt[c]`：当前窗口中颜色 \(c\) 出现次数；
- `need`：还“未满足”的颜色数量，即有多少种颜色满足 `cnt[c] < k[c]`。

初始时窗口为空，`need` 等于所有 \(k_c>0\) 的颜色数量。

右端点 \(r\) 从左到右移动，把 \(a[r]\) 加入窗口。  
如果某个颜色加入后刚好达到要求，就令 `need` 减一。

当 `need == 0` 时，说明当前窗口满足所有颜色至少出现 \(k_i\) 次，此时：

- 用当前窗口长度更新答案；
- 尝试移动左端点 \(l\) 缩小区间；
- 如果移除 \(a[l]\) 后会导致某种颜色不再满足要求，则令 `need` 加一。

伪代码如下：

```text
读入 n, m, a, k

K = sum(k)

统计整个序列中每种颜色总数 total
for c in colors:
    if total[c] < k[c]:
        print -1
        return

if K == 0:
    print 0
    return

cnt = [0] * m
need = number of c with k[c] > 0
ans = INF
l = 0

for r = 0 .. n-1:
    c = a[r]
    cnt[c]++

    if k[c] > 0 and cnt[c] == k[c]:
        need--

    while need == 0 and l <= r:
        ans = min(ans, r - l + 1)

        c = a[l]

        if k[c] > 0 and cnt[c] == k[c]:
            need++

        cnt[c]--
        l++

if ans == INF:
    print -1
else:
    print ans - K
```

## 正确性说明

**引理 1**：若存在区间 \([l,r]\) 中每种颜色出现次数不少于 \(k_i\)，则可以只删除区间内多余元素，使得剩余部分满足要求，删除次数为 \((r-l+1)-K\)。

因为每种颜色至少出现 \(k_i\) 次，所以可以每种颜色只保留任意 \(k_i\) 个，删掉其余元素。剩余元素仍然连续，且各颜色数量恰好为 \(k_i\)。

**引理 2**：任意一种合法删除方案，都可以对应到原序列中的某个区间 \([l,r]\)，使得该区间内每种颜色至少出现 \(k_i\) 次，且删除次数不少于 \((r-l+1)-K\)。

考虑删除后剩余序列中满足要求的那段连续区间。它在原序列中对应位置的首尾之间形成一个原区间 \([l,r]\)。  
为了让这段成为剩余序列中的连续区间，原区间中不属于目标区间的人必须被删除。  
因此该原区间至少包含目标所需的全部颜色数量，并且删除数至少为区间长度减去 \(K\)。

结合两条引理，最优解正是：

\[
\min_{[l,r]\text{ 满足条件}} (r-l+1) - K
\]

滑动窗口会枚举并维护所有满足条件的窗口，同时不断收缩左端点，因此能找到最短的满足条件区间，得到正确答案。

---

## 复杂度

- 时间复杂度：\(O(n+m)\)
- 空间复杂度：\(O(n+m)\)

每个元素最多被右指针加入一次、被左指针移除一次。

## 实现细节与易错点

1. **总数量不足时直接输出 \(-1\)**  
   如果存在颜色 \(c\)，整个序列中颜色 \(c\) 的总数都小于 \(k_c\)，则无论怎么选区间都不可能满足要求。

2. **区间外的元素不用删除**  
   因为题目只要求剩余序列中存在一段满足要求的连续区间，不要求整个剩余序列都满足要求。

3. **注意 \(k_c=0\) 的颜色**  
   这种颜色天然满足要求，初始化 `need` 时不要计入。删除元素时也不要错误地增加 `need`。

4. **答案为最短区间长度减去 \(K\)**  
   因为区间内至少要保留 \(K=\sum k_i\) 个目标武士，其余都是需要删除的多余元素。

5. **若所有 \(k_i=0\)**  
   此时不需要保留任何目标武士，答案为 \(0\)。

## 类似题/延伸

- 最短包含指定频数要求的子数组；
- 双指针维护“所有限制均满足”的窗口；
- 若限制不是“至少”而是“恰好”，通常需要结合前缀和、哈希或二分答案；
- 若颜色数很多但 \(k_i>0\) 的很少，可以用哈希表优化窗口状态维护。
