# Changelog

## 1.0.0

首个 Marketplace 版本（扩展名 `algorithm-training-tool`）。

- Competitive Companion 接收器（默认端口 27121）：浏览器解析题目，自动生成 cpp/json/md/.cph，不依赖 Cookie
- 样例自测：计分、单测、自定义测试、实时编辑、浏览器提交
- AI 助手：找错、审思路、题解、调题单、复盘优化
- 同题 AC 查询（Codeforces 公开 API）
- 题解社区（本地 `training/community/`）
- 五平台 handle：Codeforces / 洛谷 / 牛客 / LeetCode / AtCoder
- 账号登录 / Cookie 管理 / Gym 状态提示
- 浏览器登录与浏览器自动提交（实验性，CF/AtCoder）
- 训练面板分组 UI、等待动画、配置/文档
